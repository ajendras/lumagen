## [0.1.0] - 2026-11-17

### Added

- AI Scene Gen — Converts plain-English prompts into complete WGSL shaders, JS logic and uniform metadata via Ollama.
- Live Preview — Real-time WebGPU canvas that instantly reflects prompt changes, uniform tweaks and animation updates.
- One-File Export — Bundles scene into a single dependency-free HTML under 100 KB ready for sharing or embedding.
- Smart Controls — Auto-generates pastel sliders, color pickers and toggles for every uniform the AI exposes.
- Template Gallery — Curated starters including kelp forests, sunbeams, particle fields and fractal explorers.
- Perf Monitor — Built-in FPS counter, draw-call stats and GPU timing to keep scenes running smoothly.
- Partial Remix — Regenerate only lighting, motion or color via targeted prompts while preserving the rest.
- Copy Blocks — One-click extraction of shader, JS or full HTML for quick iteration in any editor.
